# Phase 15C trust threat model

Status: production-oriented **Experimental security profile**; not externally audited or formally verified.

The protected flow is Agent Provider / Passport Issuer → Host Application → External Agent for an organization/workspace. Direct autonomous agent coordination is outside the Core and Governed trust acceptance boundary.

| Threat | Participant / precondition | Impact | Prevention | Detection | Recovery | Remaining risk |
|---|---|---|---|---|---|---|
| Forged or modified Passport | Host; attacker supplies object | False agent identity/authority | Purpose-scoped JWS, exact issuer, digest and time checks | Proof rejection audit/metric | Block install; refresh metadata/JWKS | Approved issuer can still misrepresent product |
| Modified Capability Contract or substitution | Host; contract separated from Passport | Hidden risk/authority change | Signed manifest with exact contract digests and set equality | Manifest mismatch event | Fetch new signed version; block governed use | Semantic ambiguity needs external review |
| Forged Install resolution | Host; grant endpoint attacked | Tenant/capability confusion | One-time opaque grant plus issuer proof, audience and scope | Resolution proof/replay events | Invalidate grant; suspend install | Endpoint availability attacks |
| Forged Connection Offer | Host; offer replaced | Credential/runtime redirection | Signed/digest-bound offer without credentials | Offer proof and origin diagnostics | Reject; invalidate grant | Compromised issuer may publish malicious runtime |
| Forged Execution Receipt | Host/auditor; result replaced | False evidence | Passport-authorized execution key and signed digests | Receipt proof event | Mark invalid; preserve evidence | Digest does not prove business truth |
| Attacker-controlled metadata | Host; discovery intercepted | Key-set substitution | HTTPS exact origin, root pin, proof, sequence | Origin/proof/rollback diagnostics | Suspend issuer; out-of-band review | CA/domain takeover |
| Malicious key URL / SSRF / DNS rebinding | Host; crafted issuer/header | Internal network access | Derived well-known URL, scheme/IP checks, no header URLs, manual redirects, local allowlist | Unsafe-target errors | Block target; clear caches | DNS pinning depends on HTTP runtime |
| Cross-origin redirect | Host; discovery redirect | Issuer substitution | Redirects rejected by default and revalidated | Discovery failure audit | Administrator review | Same-origin service compromise |
| Compromised operational key | All; private signing service breached | Forged new objects | Purpose separation, short validity, prepublished replacement | Revocation/key-state refresh | Compromise → revocation, cache invalidation, replacement Passport | Unknown compromise start makes history uncertain |
| Compromised root key/domain | All; root or issuer control lost | Entire issuer impersonation | Root isolation/pins and low-volume use | Unexpected pins/origin/status | Suspend; out-of-band admin recovery | Cannot be fully automated |
| Stale JWKS/revocation cache | Host; network unavailable | Revoked key remains usable | Bounded cache, nextUpdate, sequence, emergency refresh | Freshness status/metric | High-risk fail closed; invalidate | Availability vs freshness tradeoff |
| Metadata/revocation rollback | Host; old signed snapshot replayed | Restored compromised state | Monotonic persisted sequence and digest chain | Rollback audit | Reject and refresh; administrator alert | Loss of anti-rollback storage |
| Duplicate `kid` / collision / material replacement | Host; malicious JWKS | Wrong key resolution | Unique bounded `kid`, thumbprint equality, retained history | JWKS validation | Reject entire set; suspend issuer | Deliberate issuer equivocation across hosts |
| Algorithm confusion / `none` / symmetric proof | Host; malicious header | Signature bypass | Host allowlist, EdDSA/key exact match, protected headers | Algorithm rejection metric | Emergency disable/deprecation | Runtime cryptographic vulnerability |
| Unsupported critical/header key references | Host; crafted JWS | Alternate interpretation/key fetch | Exact protected-header set; reject `crit`, `jku`, `x5u`, `jwk` | Proof-invalid diagnostic | Reject object | Parser differentials in other implementations |
| Signature stripping/payload replacement | Host; intermediary mutates JSON | Unsigned object accepted | Required proof per production profile; exact canonical payload | Missing proof/digest mismatch | Block operation | Legacy Core path must remain explicitly non-trust |
| Replay of install/request/approval/Invocation | Host/agent; captured message | Duplicate action | Atomic nonce/message cache separate from idempotency | Replay audit/metric | Reject authentication; preserve business idempotency result | Distributed cache consistency |
| Audience/issuer confusion | Host/agent; valid object reused | Cross-host or cross-tenant execution | Exact issuer, audience, organization, workspace, Connection | Mismatch codes | Reject; re-authenticate | Misconfigured audience |
| Cross-organization/workspace use | Company; stolen signed object | Tenant data breach | Signed scope plus mandatory organization policy; workspace only stricter | Scope mismatch/audit | Revoke Connection; incident response | Compromised host policy/admin |
| Clock-skew abuse / long-lived artifacts | All; manipulated time | Extended replay/key life | Bounded skew/lifetimes and expiry checks | Future/expired metrics | Correct clocks; rotate/reissue | Host clock compromise |
| Rotation race / revoked cached key | Host/issuer; asynchronous refresh | Temporary verification failure or excess trust | Prepublish, overlap, sequence and invalidation | Rotation/cache events | Emergency refresh; bounded overlap | Offline hosts may fail closed |
| Forged Registry trust badge | User; listing presented as approval | Social-engineering install | Separate labels: observed, cryptographic, host-approved, conformance, audit | UI contract tests | Remove label; review issuer | Users may ignore distinctions |
| Compromised host trust policy/admin | Company; privileged account breached | Malicious issuer approved | RBAC, scoped approval, versioned policy/audit | Approval-change alerts | Suspend issuer/policy; credential response | Authorized insider risk |
| Credential/private-key leakage | Provider/host; log/API/state exposure | Account/signing compromise | Non-exporting signer, redaction, public-JWK validation, no frontend keys | Secret scanning and safe tests | Rotate/revoke; incident response | Memory/process compromise |
| Development test key in production | Issuer; bad configuration | Known weak assurance | Local provider throws in production; `testOnly` metadata | Startup/config verifier | Stop service; replace all artifacts | Custom provider may mislabel a key |
| Log/metric leakage | Operator; unbounded identifiers | Secret/privacy exposure | Bounded allowlisted events; low-cardinality metrics | Contract tests | Purge per retention; rotate leaked credentials | External sink misconfiguration |
| Oversized JWKS / excessive keys / verification DoS | Host; malicious endpoint | CPU/memory exhaustion | Byte/key/proof limits, timeouts, bounded concurrency policy | Size/time metrics | Quarantine issuer; backoff | Valid signature verification remains CPU work |
| Unicode/canonicalization ambiguity | Cross-implementation; equivalent-looking JSON | Signature differential | One canonical profile, valid Unicode, vectors | Conformance mismatch | Reject/reissue | Future cross-language edge cases |
| Duplicate JSON keys / prototype pollution | Host; crafted raw JSON | Parser confusion/object mutation | Strict raw parser and prohibited keys | Parse rejection | Reject request | Framework may parse before verifier if miswired |
| Historical Receipt after compromise | Auditor; compromise time uncertain | Overstated evidence | Separate at-issuance/current state and indeterminate result | Historical classification | Preserve Receipt with warning | Truth cannot be recovered for unknown compromise period |
| Revocation endpoint compromise | Host; attacker publishes set | False active/revoked state | Purpose key, sequence, digest chain, issuer binding | Proof/rollback detection | Suspend issuer; root-authorized recovery | Current signer can issue malicious status |
| Metadata key-set substitution | Host; valid metadata points elsewhere | Attacker keys trusted | Same-origin endpoint by default, root proof and root pins | Endpoint/pin mismatch | Reject metadata | Root-authorized malicious change |
| Approval replay | Governed agent; captured approval | Repeated high-impact action | Approval binds Invocation/action/scope/expiry and one-time state | Approval replay event | Reject; new challenge | Distributed approval-state consistency |
| Authentication downgrade | Host/provider; profile mismatch | Unsigned request accepted | Negotiated profile bound to Connection; no silent fallback | Auth-profile mismatch | Reconnect/review | Explicit local `none` remains weaker |

## Operational review

External review is still required for HTTP stack DNS pinning, cross-runtime canonicalization, JOSE interoperability, key-provider/HSM integrations, distributed replay atomicity, administrator/RBAC enforcement, incident procedures, dependency supply chain, performance limits, and all public security claims.
