# Capability Contract

A Capability Contract defines a versioned capability key, safe description,
input/output Data Contract references, accepted/produced/prohibited data
classes, risk and side-effect category, idempotency, async/cancellation support,
permissions, approval and delegation rules, timeouts, receipts, lifecycle
status, deprecation, and namespaced extensions.

Rules are declarative data. Arbitrary executable policy or transformation code
is not portable protocol content.
