# Terminology

- **Ghost Bridge Native:** the native wire protocol.
- **Agent Passport:** a versioned, verifiable declaration of agent identity.
- **Passport Issuer:** issues and maintains a Passport.
- **Capability Contract:** governed declaration of what an agent can perform.
- **Install Grant:** short-lived, bounded, redeemable installation authorization.
- **Agent Connection:** installed relationship between an organization and agent.
- **Invocation Envelope:** scoped request to execute one capability.
- **Delegation Grant:** limited authority for one agent to request another.
- **Data Contract:** permitted fields and data classifications across a boundary.
- **Approval Challenge / Decision:** protocol request and response for human authorization.
- **Execution Task:** observable lifecycle for asynchronous or durable work.
- **Execution Receipt:** verifiable evidence of an execution outcome.
- **Revocation:** authoritative invalidation of a trust subject.
