# Participants

- **Agent Provider:** builds, publishes, or operates an external Native Agent.
- **Passport Issuer:** issues, rotates, suspends, and revokes Passports.
- **External Native Agent:** implements declared Capability Contracts.
- **Host Application:** the product into which a user installs an external Agent.
- **Host Client:** the SDK component that resolves grants, evaluates
  compatibility, installs, invokes, observes, and revokes Agents. Older text
  may call this participant a Client.
- **Operator:** operates a compatible control plane.
- **Organization:** owns the top-level tenant scope.
- **Workspace:** bounded operating scope inside an Organization.
- **Approver:** authorizes a high-impact action.
- **Registry:** future optional discovery mechanism; not required in 0.1-draft.
- **Ghost Bridge Platform:** one complete commercial implementation.
