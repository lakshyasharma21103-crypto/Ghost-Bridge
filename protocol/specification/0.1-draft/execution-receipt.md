# Execution Receipt

A Receipt records the Invocation and Task, Agent/Passport and Capability
versions, tenant scope, outcome, output contract, time bounds, attempts,
Approval/Delegation/policy references where safe, output/evidence digests,
declared billing category, revocation state, and optional proof.

Receipts are evidence, not unrestricted logs. They exclude raw credentials,
provider payloads, unrestricted inputs/outputs, prompts, hidden reasoning,
private memory, and private policy rules.
