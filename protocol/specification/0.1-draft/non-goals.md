# Non-goals

Ghost Bridge Protocol does not require MongoDB, Redis, any database or queue, a
cloud, the Ghost Bridge frontend, billing/analytics/worker implementations, a
policy engine, identity provider, model provider, source-code disclosure,
system-prompt disclosure, chain-of-thought or hidden-reasoning disclosure, or
private-memory disclosure.

It defines portable data and behavior, not implementer infrastructure. The
commercial Platform is one implementation and is not required.
