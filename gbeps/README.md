# Ghost Bridge Enhancement Proposals

GBEP means Ghost Bridge Enhancement Proposal. Proposals document changes to the
protocol, project process, informational guidance, or extension lifecycle.

Statuses are Draft, Review, Accepted, Final, Rejected, Withdrawn, and
Superseded. Proposal types are Standards Track, Process, Informational, and
Extensions Track.

The current process is an initial owner-led draft. Proposals are not merged
automatically and do not imply neutral governance.
