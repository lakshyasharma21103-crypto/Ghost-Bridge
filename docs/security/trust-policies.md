# Trust policies

Organization policy controls issuer allow/block lists, root pins, algorithms, profile, lifetime/cache/freshness, conformance, authentication, risk/side effects, Receipt/approval support, unknown issuers, fetch failures, and compromise behavior.

Workspace policy may be stricter but never weakens mandatory organization rules. Unknown issuers choose block, administrator review, or limited Core-only use; high-impact Governed actions never silently trust them.
